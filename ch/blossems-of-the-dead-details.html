Before You Cross

项目简介

《Before You Cross》是我在伦敦大学金史密斯学院游戏设计课程中，为毕业项目制作的一款游戏。 这是一款使用虚幻引擎开发的 3D 解谜平台游戏，我与另外三名团队成员共同完成了这款作品。

玩家角色将在死者之地中探索，通过切换不同的灵魂形态来解决谜题，并最终找到已故的祖母，向她道别。 维度切换是游戏的核心循环，玩家需要在不同灵魂形态之间切换，以解决环境谜题并探索这个世界。

我负责以下工作：

  • 编写游戏核心机制与系统
  • 设计与灵魂切换相关的游戏机制
  • 设计游戏界面的 UI/UX

程序编写

我的职责

作为本项目的主要技术设计师与程序员，我不仅负责实现游戏中的大部分机制， 还要确保程序结构清晰、易于维护和重复使用，并让这些机制能够以合理的工作量完成实现。

作为一款维度切换解谜平台游戏，本作会将玩家在沿 Y 轴排列的两个平行世界之间传送。 两个世界共享部分子关卡，因此共享的资产与互动道具都可以在同一个场景中统一更新。 检查点系统、火焰互动道具、敌人行为，以及其他在不同世界中具有不同属性的对象，均被整合进这套维度切换系统。

风与火焰的粒子效果通过材质着色器和 Niagara 粒子系统实现。该系统提供了大量参数设置， 能够高效地产生粒子，同时确保最佳的视觉效果。

我还主要负责实现游戏第二关中的八卦匹配谜题系统，玩家需要将获得的画作与八卦中的卦象进行匹配。 我采用数据驱动的方法，由一个模块化脚本处理所有卦象，并使用每个对象的精灵引用作为唯一 ID，验证画作是否放置正确。

版本控制

本项目使用版本控制，并以 Perforce 作为主要的版本控制软件。我协助设置 Perforce 服务器， 并帮助团队成员配置客户端。

机制设计

我的职责

我的任务是思考有趣的机制设计，为游戏增加更多变化，避免它变成单纯的步行模拟游戏。 虽然最终并非所有想法都被选用和实现，但每个想法都会通过绘制图表进行充分推演。

我的想法

状态切换被确定为游戏的主要机制，因此我提出了许多围绕状态切换展开的子机制。 由于状态切换机制以太阳火焰为基础，我思考了火焰如何被风吹灭，以及如何点燃物体，并在此基础上延伸出更多想法。 下方图表仅展示了我计划并与团队讨论过的部分想法。

我还设计了位于第二关一座高塔底层的八卦匹配谜题系统。由于游戏中的其他谜题对于大学项目来说流程相对较长， 因此我决定设计一个易于理解且操作简单的谜题。玩家需要在高塔中寻找画作，将它们放入八卦中正确的卦象位置， 并通过展示匹配图案的广告牌获得提示。

UI/UX 设计

我的职责

我设计并实现了游戏的完整 UI 与 UX 系统，涵盖抬头显示界面和世界空间中的互动对象。 这些 UI 与 UX 元素以简洁为设计目标，同时为玩家提供信息并改善游戏内的导航体验。

我的想法

和我通常规划 UI 设计的方式一样，我会先制作带有注释的线框图，待团队达成共识后，再将设计实现为最终界面。 由于玩家将在游戏中获得 3 个太阳火焰，抬头显示界面会展示火焰的收集进度。 我最初为 3 个可收集的太阳火焰设计了带冷却条的界面，但在冷却机制被删去后，便将设计简化了。

游戏内 UI 线框状态 2［已弃用］

游戏通过对话框和过场动画向玩家呈现文本，以丰富叙事并完善世界观塑造。 最初，我只设计了在玩家与角色进行实体互动时出现的可互动对话框。 后来发现玩家没有足够时间逐一与区域内的每个 NPC 互动，因此我参考了《纸片马里奥》等游戏， 在 NPC 上方设计了浮动对话框，并在玩家进入 NPC 一定距离内时触发。

游戏包含开场和结尾过场动画。由于开发时间有限，这些内容必须以简单、易于编辑和维护的方式实现。 我选择使用静态图片展示特定事件，并在图片底部配上文字。

最终实现

对象互动是游戏的重要组成部分，玩家需要知道哪些对象可以互动，哪些对象不能互动。 最初，玩家触手可及的互动对象会在网格外显示黄色轮廓；但后来发现这种方式对部分玩家来说不够明显， 因此改为使用蓝色材质高亮网格。 在八卦匹配谜题中，颜色变化不仅用于表示可互动的卦象，也用于表示画作在八卦中的正确放置位置。
